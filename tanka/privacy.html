プライバシーポリシー (Privacy Policy)

最終更新日 / Last Updated: 2026年10月31日

「Short Verse Studio」（以下、「本アプリ」といいます）は、ユーザーのプライバシーを最優先事項として尊重し、個人情報の保護に最大限の配慮を行っています。本プライバシーポリシーでは、本アプリにおけるユーザーデータの取り扱いについて説明します。

1. 取得する情報およびその利用目的

本アプリは、ユーザーが入力した短詩文芸（俳句、短歌、絶句、時調、ルバイヤート、ガザル、リメリック、エピグラム）をブラウザ内のCanvasおよびWebCodecsを用いて縦型動画（MP4）へ変換し、ユーザー自身のYouTube™ チャンネルへアップロードする機能を提供します。

  • 詩作テキストおよび生成動画データ: すべての動画生成処理はユーザーのブラウザ内（ローカルメモリ上）で完結します。開発者のサーバーへ送信・保存されることは一切ありません。
  • Google / YouTube™ OAuth 認証情報（https://www.googleapis.com/auth/youtube.upload）: ユーザーが明示的にアップロード操作を行った際、ユーザーのブラウザから直接 YouTube™ Data API v3 へ動画を送信する目的でのみ一時的なOAuthアクセストークンを使用します。

2. 通信の暗号化とデータの非保持（データ保存ゼロ原則）

本アプリのすべての通信および Google API とのデータ送受信は HTTPS / TLS 1.2 以上 により暗号化されます。本アプリは独自のバックエンドデータベースを持たず、ユーザーの個人情報、認証情報、入力テキスト、動画ファイルを外部サーバーやストレージに保存・蓄積することは一切ありません。

3. Google API 限定使用ポリシーおよび YouTube™ API 規約の遵守

本アプリが Google API から受け取った情報の使用および他のアプリへの転送は、限定使用の要件（Limited Use requirements）を含め、Google API サービスのユーザーデータポリシーに準拠します。また、本アプリは YouTube™ API サービスを利用しており、ユーザーはGoogleのプライバシーポリシー（http://www.google.com/policies/privacy）および Google セキュリティ設定ページ からいつでも本アプリのアクセス権限を取り消すことができます。

4. 第三者への非販売・AI学習への非利用

本アプリは、取得したユーザーデータをいかなる第三者にも開示、販売、共有、提供することはありません。また、ユーザーデータを広告配信目的や、汎用AI・機械学習（AI/ML）モデルのトレーニング・学習に使用することは一切ありません。

5. 広告配信およびアフィリエイトプログラムに関する表記

本サイト（wasabikarashi.com）では、第三者配信の広告サービス（Google AdSense）および関連書籍紹介のためのアフィリエイトプログラム（楽天アフィリエイト、Amazonアソシエイト等）を利用する場合があります。Google などの第三者広告配信事業者は、Cookie を使用してユーザーが本サイトや他のウェブサイトに過去にアクセスした際の情報に基づいて広告を配信することがあります。ユーザーは Google の広告設定 でパーソナライズ広告を無効にすることができます（※なお、Google OAuth / YouTube™ API から取得したユーザーデータを広告配信やターゲティングに使用することは一切ありません）。
