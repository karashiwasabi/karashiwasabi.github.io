[English Version]

"Line-aligned" (hereinafter referred to as "the Application", "we", "us", or "our") respects user privacy and is committed to protecting your personal information. This Privacy Policy outlines how user data is accessed, processed, and safeguarded when using our Google Docs™ Add-on.

1. Information Accessed and Purpose of Use

Line-aligned is designed solely to typeset and format documents into standard loose-leaf notebook rulings (B5/A4) and generate print-ready PDF files directly into the user's Google Drive. To accomplish this, the Application accesses:

  • Document Content and Structure: Text, headings, formatting styles, tables, and images of the active document are accessed temporarily to compute precise line-aligned typography.
  • OAuth Access Tokens: Temporary, short-lived OAuth credentials provided by Google are used strictly to authorize authorized API calls on your behalf.

2. Data Protection Mechanisms for Sensitive Data

We implement strict technical and organizational safeguards to ensure user data remains secure:

  • Encryption in Transit: All data transmitted between the user's browser, Google Workspace services, and our backend typesetting engine (hosted on Google Cloud Run) is strictly encrypted in transit using industry-standard HTTPS / TLS 1.2 or higher protocols.
  • Stateless In-Memory Processing (Zero Persistent Storage): Line-aligned operates completely statelessly. Document contents, text, and images are processed strictly in volatile system memory during PDF rendering. No user document data, personal information, or generated PDFs are ever saved, cached, or logged to persistent disks or databases.
  • Immediate Data Deletion: Memory buffers containing document data are automatically purged immediately after the typesetting computation and PDF generation are completed.

3. Data Retention and Deletion

Because Line-aligned does not store or persist any user data on its servers, there is no user data stored to retain. Users have complete control over their authorization and can revoke Line-aligned's access permissions at any time via Google Account Permissions Settings or by uninstalling the Add-on.

4. Compliance with Google API Services User Data Policy

Line-aligned's use and transfer to any other app of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. Third-Party Sharing and Non-Sale of Data

We do not sell, rent, trade, lease, or share user data with any third parties under any circumstances. Furthermore, user data is never used for advertising, marketing, or training general artificial intelligence (AI) / machine learning models.

6. Contact Information

If you have any questions, concerns, or inquiries regarding this Privacy Policy or data security practices, please contact us at:

Email: shintanikarashi@gmail.com

7. Notification of Changes to Google User Data Usage

If we change how Google user data is accessed, used, stored, or shared, we will notify users in advance by posting a prominent notice on our website (https://wasabikarashi.com/) and within the Application before any changes take effect.

[日本語版]

「Line-aligned」（以下、「本アプリ」といいます）は、ユーザーのプライバシーを最優先事項として尊重し、個人情報の保護に最大限の配慮を行っています。本プライバシーポリシーでは、本アプリにおけるユーザーデータの取り扱いおよび保護措置について説明します。

1. 取得・アクセスする情報およびその利用目的

本アプリは、Google ドキュメント™ のテキスト、見出し、図表をルーズリーフノート形式へ再組版・整形し、Google ドライブへPDFを出力する機能を提供します。この目的を達成するために以下のデータにアクセスしますが、保存・蓄積は一切行いません。

  • ドキュメントコンテンツ: 組版計算およびPDF生成処理のためにのみメモリ上で一時的に処理されます。処理完了後、データは即座に破棄され、サーバーに永続的に保存されることはありません。
  • 一時的OAuth認証情報: Google API へのリクエストを安全に実行するために一時的なOAuthアクセストークンを使用します。

2. 機密データの保護メカニズム（暗号化および非保持）

本アプリは、ユーザーデータの機密性と安全性を保護するため、以下の厳格な安全管理措置を実施しています：

  • 転送時暗号化: ユーザーのブラウザ、Google Workspace、およびバックエンド組版エンジン（Google Cloud Run）間のすべての通信は、業界標準の HTTPS / TLS 1.2 以上 のプロトコルを用いて完全に暗号化されます。
  • 完全ステートレス処理（保存ゼロ原則）: 本アプリは完全ステートレスに動作します。ドキュメントのテキストや画像データはPDF生成処理中の揮発性メモリ上でのみ処理され、外部データベース、永続ディスク、ログファイル等にいかなるユーザーデータも保存・蓄積しません。
  • 即時破棄: 組版処理およびPDFの出力が完了した瞬間、メモリ上のデータは即時に完全に破棄されます。

3. データの保持および削除

本アプリはサーバー上にいかなるユーザーデータも永続保持しないため、サーバー側に保持される個人データは存在しません。ユーザーは、Google アカウントのセキュリティ設定 またはアドオンのアンインストールにより、いつでも本アプリへのアクセス権限を取り消すことができます。

4. Google API サービス ユーザーデータ ポリシーの遵守

本アプリが Google API から受け取った情報の使用および他のアプリへの転送は、関連する制限要件を含め、Google API サービスのユーザーデータ ポリシー（限定使用要件）に厳格に準拠します。

5. 第三者への開示・提供および非販売の徹底

本アプリは、取得したデータをいかなる第三者にも開示、販売、貸与、共有、提供することは一切ありません。また、広告目的やAIモデルの一般的な学習用途にデータを利用することもありません。
