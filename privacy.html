プライバシーポリシー

最終更新日: 2026年10月5日

「Line-aligned」（以下、「本アプリ」といいます）は、ユーザーのプライバシーを最優先事項として尊重し、個人情報の保護に最大限の配慮を行っています。本プライバシーポリシーでは、本アプリにおけるユーザーデータの取り扱いについて説明します。

1. 取得する情報およびその利用目的

本アプリは、Google ドキュメント™ のテキスト、数式、図表をルーズリーフノート形式へ再組版・整形し、PDFを出力する機能を提供します。この目的を達成するために以下のデータにアクセスしますが、保存・蓄積は一切行いません。

  • ドキュメントコンテンツ: 組版計算およびPDF生成処理のためにのみメモリ上で一時的に処理されます。処理完了後、データは即座に破棄され、サーバーに永続的に保存されることはありません。
  • 基本認証情報: Google API へのリクエストを安全に実行するために一時的なOAuthアクセストークンを使用します。

2. データの非保持（データ保存ゼロ原則）

本アプリは、いかなるユーザーのドキュメントデータ、個人情報、ファイル内容もデータベースや外部ストレージに保存しません。すべての組版処理はステートレスに行われます。

3. Google API 限定使用ポリシーの遵守

本アプリが Google API から受け取った情報の使用および他のアプリへの転送は、関連する制限要件を含め、Google API サービスのユーザーデータポリシーに準拠します。

4. 第三者への開示・提供

本アプリは、取得したデータをいかなる第三者にも開示、販売、共有、提供することはありません。
