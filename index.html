仕様・制限事項

本ツールは「手書きしやすい学習ノートへの最適化」を目的として再組版を行うため、以下の仕様・制限事項がございます。

  • Google ドキュメント™ の見た目の完全再現ではありません 文字をノート罫線上に美しく乗せるため、行間や行末の折り返し位置は「ノート最適化ルール」に基づいて再計算・再配置されます。
  • 横書き専用（縦書きは非対応） 横書きドキュメントのみに対応しています。縦書き文書の組版には対応しておりません。
  • 1ページを超える巨大な表のページ跨ぎ分割 表は1ページ内に収まるサイズを想定しています。1ページの筆記高さを超える巨大な表は、ページ途中での自動分割は行われず、次のページへ送られます。
  • 複雑な自由配置テキストボックス・レイヤー重ね合わせ 本文から独立して自由に浮動配置されたテキストボックスや、文字と画像の重ね合わせ（前面/背面配置）は、本文の流れに沿ったインラインブロックとして再配置されます。
  • フォントの統一（仕様・品質確保） ルーズリーフの罫線と文字の位置を正確に一致させるため、ドキュメント側のフォント設定に関わらず、印刷・視認性に優れた標準フォント（ゴシック体／明朝体）で統一してPDFを出力します。

Specifications & Limitations

As this tool reformats documents specifically to optimize them as handwritten study notebooks, the following specifications and limitations apply:

  • Not a 100% replica of Google Docs™ visual layout Line spacing and line wrapping are recalculated and repositioned based on notebook optimization rules to align text cleanly with notebook ruling lines.
  • Horizontal text only (Vertical text not supported) Supports horizontal documents only. Vertical document layout is not supported.
  • Multi-page split for oversized tables Tables are expected to fit within a single page. Tables exceeding one page in height will not be automatically split across pages and will be pushed to the next page.
  • Floating text boxes and layered overlays Floating text boxes and overlapping images/text are reformatted as inline blocks aligned with the main body text flow.
  • Font standardization (Quality assurance) To ensure accurate alignment with notebook ruling lines, standard high-legibility fonts (Gothic / Mincho) are applied uniformly for PDF output, regardless of original document font settings.

规格与使用限制说明

为了将文档重排为适合手写记笔记的“学习笔记本”，本工具具有以下规格和限制说明：

  • 并非完全复刻 Google 文档™ 的原始外观 为了让文字与笔记本横线精准对齐，行距与自动换行位置会根据笔记本优化规则重新计算与排版。
  • 仅支持横排（不支持竖排文本） 仅支持横向排版的文档，不支持竖排文字排版。
  • 超大表格跨页分割说明 表格建议控制在单页内。高度超过单页书写区域的巨大表格不会自动跨页拆分，而是整体移至下一页。
  • 浮动文本框与多图层叠加 正文外浮动的文本框以及文字与图片的叠加图层，将重新排版为跟随正文流的嵌入式块。
  • 字体统一（排版规范与质量保障） 为了保证打印时文字与活页纸横线精准贴合，无论原文档采用何种字体，输出 PDF 时均统一采用高清晰度的标准字体。

사양 및 제한 사항

본 툴은 '손글씨 쓰기 편한 학습 노트 최적화'를 목적으로 재조판을 진행하므로, 다음과 같은 사양 및 제한 사항이 있습니다.

  • Google 문서™ 화면의 완전한 복제가 아닙니다 글자를 노트 줄눈 위에 아름답게 맞추기 위해, 줄 간격과 줄 바꿈 위치는 '노特'가 아닌 '노트 최적화 규칙'에 따라 재계산 및 재배치됩니다.
  • 가로쓰기 전용 (세로쓰기 미지원) 가로쓰기 문서만 지원하며, 세로쓰기 문서는 지원하지 않습니다.
  • 1페이지를 초과하는 대형 표의 페이지 분할 표는 1페이지 내에 들어가는 크기를 권장합니다. 높이가 1페이지를 초과하는 대형 표는 중간 자동 분할 없이 다음 페이지로 넘어갑니다.
  • 복잡한 자유 배치 텍스트 상자 및 레이어 겹침 본문과 분리된 자유 부동 텍스트 상자나 텍스트-이미지 겹침 배치는 본문 흐름에 맞춘 인라인 블록으로 재배치됩니다.
  • 폰트 통일 (품질 및 규격 보장) 루즈리프 줄눈과 글자 위치를 정확하게 일치시키기 위해, 원본 폰트 설정과 관계없이 가독성이 뛰어난 표준 폰트로 통일하여 PDF를 출력합니다.
